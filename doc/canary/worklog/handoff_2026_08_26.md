## 3. The plan

The frame is [`plan.md` §4](../plan.md): five stages from theory
to a merged PR, each with a status and an owner. Condensed:

| # | Stage | Status |
| --- | --- | --- |
| 1 | theory — surfaces + agreements | model landed; catalogue **3/20** |
| 2 | checker — a contract with a tool-grounded falsifier | c1..c8 wired; per-project tables not converged |
| 3 | world — the project's 2×2 | **the working part**: 10 projects, 42 scenarios, 41 run |
| 4 | finding — a red cell with readable evidence | evidence readable since 2026-08-20; blame framing not lifted |
| 5 | fix — upstream PR | **not started — 0 PRs** |

**The point of the frame:** landing a project is cheap now, so the roster
reads as progress it is not. A landed project runs the checks its own
spec happens to name. Growing the roster without stage 2 adds rows, not
claims. Stage 5 is the largest hole in the paper's central argument.

## 5. Environment notes that bite

- **The canary opam switch.** Canary defaults to its own switch
  (`canary`, OCaml 5.4.1) and the switch is part of the step
  fingerprint, so a verdict earned in one switch is never served to
  another. If the WSL box's switch differs, expect a cold run — that is
  correct behaviour, not a cache bug.
- **`--platform=<macos|wsl>`** renders the other machine's view; an
  overridden run never writes `docs/` (see §0.4).
- **CLAUDE.md still carries `/home/red` paths** in the worktree section
  from the earlier Linux box. Harmless as prose, wrong as a path.
